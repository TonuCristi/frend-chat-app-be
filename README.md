# 💬 Real-Time Chat Application (Backend)

A scalable backend service for a real-time chat application built with Node.js, Express, and MongoDB.

This API handles authentication, user management, message management, and real-time communication using WebSockets.

---

## 🚀 Features

- User authentication (registration & login)
- Account and user profile management
- Real-time messaging using WebSockets
- Secure API structure
- Data persistence with MongoDB
- Scalable backend architecture

---

## 🧠 Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- WebSockets

---

## 🛠️ Key Concepts Implemented

- REST API design
- Authentication & authorization
- WebSocket server implementation for real-time communication
- Database modeling with Mongoose
- User session handling
- Scalable backend architecture
